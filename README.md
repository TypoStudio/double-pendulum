# Double Pendulum — 이중 진자

고정축 O · 관절축 P₁ · 추 P₂, 2축 3점 이중 진자의 카오스 운동 시뮬레이션.

**Live**: https://typostudio.github.io/double-pendulum/

- RK4 적분, 드래그로 초기 각도 설정
- 막대 길이 · 질량 · 중력 · 감쇠 · 배속 · 잔상 길이 조절
- 궤적 영구 보존 모드 (하모노그래프처럼 잉크가 쌓임)
- 움직이는 모든 점(관절축·추·태양·행성)이 궤적을 남김
- 쌍둥이 진자/행성 — 초기 조건 민감성 시각화
- 소설 『삼체』 프리셋: 항세기 / 난세기(삼일능공, g = 3×9.8)
- **삼체 궤도 모드**: 태양 A·B·프록시마(질량비 1.1/0.9/0.12)가 만유인력으로
  춤추는 실제 다체 시뮬레이션 — 자동 추적 카메라, 행성 탈출 반사
