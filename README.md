# Double Pendulum — 이중 진자

2축 3점 이중 진자에서 시작해, 같은 RK4 엔진으로 다체 중력까지 다루는 카오스 운동
시뮬레이션. 세 가지 모드가 한 화면에 들어 있습니다.

**Live**: https://typostudio.github.io/double-pendulum/

## 이중 진자

고정축 O · 관절축 P₁ · 추 P₂의 2축 3점 진자.

- RK4 적분, 드래그로 초기 각도 설정
- 막대 길이 · 질량 · 중력 · 감쇠 · 배속 · 잔상 길이 조절
- 궤적 영구 보존 모드 (하모노그래프처럼 잉크가 쌓임)
- 움직이는 모든 점이 궤적을 남김
- 쌍둥이 진자 — 초기 조건 민감성 시각화
- 소설 『삼체』 프리셋: 항세기 / 난세기(삼일능공, g = 3×9.8)

## 삼체 궤도

태양 A·B·프록시마(질량비 1.1 / 0.9 / 0.12)가 만유인력으로 춤추는 실제 다체
시뮬레이션. 행성은 그 중력장을 떠도는 시험 입자입니다.

- 세 항성을 따라가는 자동 추적 카메라
- 궤도와 동시에 보는 하단 파노라마 — 세 태양의 거리별 겉보기 크기, 일출·일몰,
  낮·밤의 하늘과 바다, 행성 자전 및 본초자오선 표시
- 항세기(안정 위계) / 난세기(카오스 무도) 프리셋
- 쌍둥이 행성으로 궤도 분기 관찰

## 스윙바이

태양(M=30) · 지구(R=2.2) · 목성(R=5, M=0.35)의 중력장을 탐사선이 항행합니다.
행성 질량과 궤도 간격은 서로의 공전궤도를 흔들지 않는 값으로 맞췄습니다
(15 시간단위 동안 지구 궤도 반경 변동 ±1%).

프리셋 세 가지 — 초기 조건은 모두 수치 탐색으로 찾았습니다:

| 프리셋 | 여정 |
|---|---|
| **목성 왕복** | 근일점 0.8의 태양 스윙바이로 목성 도착 → 궤도 진입 → 3.3바퀴 관측(한 바퀴 4.7초) → 탈출·귀환 → 지구 안착 (약 48초) |
| **목성 탈출** | 같은 태양 스윙바이 뒤 목성 뒤쪽 0.09를 스치며 가속, 태양계 이탈 — 보이저 방식. 기동 없이 순수 중력 |
| **금성 경유** | 지구 뒤로 감속 발사 → 금성(R=1.5) 0.015 스윙바이 → 그 반동으로 목성행 → 같은 4단계 기동 → 지구 안착 (약 47초) |

- **중력 지배 표시**: 지금 탐사선의 궤도를 지배하는 천체를 강조 링·점선·라벨로
  표시 (중심별이 압도적인 스윙바이는 영향권 반지름 `r·(m/M)^0.4` 기준,
  질량이 비슷한 삼체는 인력 `GM/r²` 기준으로 자동 전환)
- **분사 지점 표시**: 궤적이 꺾이는 네 지점을 별표와 순번으로 —
  ① 목성 궤도 진입 ② 탈출 ③ 귀환 궤도 진입 ④ 지구 안착.
  무추진으로는 다바퀴 포획이 불가능해 실제 갈릴레오처럼 기동을 넣었고,
  이 네 번 외에는 전부 중력만으로 움직입니다
- 탐사선을 드래그하면 놓은 자리의 원궤도 속도로 다시 출발

## 구현 노트

- **고정 적분 스텝**: `H = 1/960`을 정수 번만 진행하고 남은 시간은 누적합니다.
  스텝 크기가 프레임 시간에 흔들리지 않으므로, 포획처럼 민감한 궤도도 주사율·기기와
  무관하게 같은 궤적으로 재현됩니다
- **부드러운 경계**: 시험 입자가 경계(r = 20) 밖으로 나가면 속도를 반사하는 대신
  깊이에 비례한 복원 가속을 줘, 보이지 않는 스프링에 걸린 듯 완만한 호로 되돌아옵니다
- 근접 특이점은 softening(ε)으로 완화

의존성 없는 단일 `index.html`. 브라우저에서 바로 열면 됩니다.
PWA manifest가 있어 모바일 홈 화면에 추가하면 전체 화면으로 실행됩니다
(모바일에서는 설정 패널이 하단 팝업으로 열립니다).
